# 第一课第8000步真实验证

第8000步在同一700道验证题中答对590题（84.29%），较6000步600题（85.71%）少10题，下降1.43个百分点。当前选模仍保留6000步，继续既定第一课训练；这不是四课结业或棋力验收。

定位与横行继续提高，同时对角线和棋子数量回落，纵列小幅下降，子力统计与识子持平。保留这些变化，不将单个检查点解释为收敛或具体故障，也不能据此确认更多训练必然提高成绩。
