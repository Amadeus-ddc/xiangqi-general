# 搜索蒸馏的新增真实棋谱

这批数据为新四课之后的搜索蒸馏补充未用实战，当前课程和初始讲解的输入保持其冻结合同。[轻量证据](../evidence/public-recorded-search-source-v1.json)记录采集、原生导入、独立复核和后续准备队列的实际状态。

匿名公开导出覆盖 PlayStrategy 象棋榜单的 200 个账号，获取 38612 条原始记录。导入要求已结束的实质对局、双方账号和至少 20 个半回合；逐步检查完整历史、终局、原始 JSON／PGN 坐标及结果。5446 条隔离、10452 条重复后，新增 **22714** 盘、**1333655** 个半回合。来源声明为人类实战 16695 盘、人机实战 6019 盘，涉及 1153 个参与者标签；账号标签不认证真实身份、无辅助下棋或走法最优性。

先按棋局固定分割，再制作候选：训练 18158、验证 2313、独立测试 2243。记录年份为 2022—2026；来源棋谱的后续着法只提供合法上下文，搜索标签仍须由实际学生、独立引擎和完整 BF16 汇总教师产生。

新增完整对局先对七份已有完整历史去重。第八份旧来源是 9683 个零步战术局面，不能传给完整对局去重接口；它仍参加后续全部局面、颜色和保留集隔离。九份来源合计的标识包括对局、片段和给定局面，不能一概称为完整棋局或合格标签。

## 接入新课程

`xqgeneral-fresh-paper-search-inputs-v1` 保存入口位于 `runs/public-search-native-publication-v1/worktree/runs/fresh-paper-search-inputs-v1/`。它等待 `data/paper-courses-v5` 的实际全量金标复核，以及全部新增棋谱的独立原生复核；不把尚未写完的课程前缀当作完整使用范围。

通过后依次执行现有公开入口：

1. `recorded_coach footprints` 提取新课程三份文件和初始讲解三份文件的棋局、根及全部已记录未来分支。
2. `search_inputs` 提取新课程实际已用训练历史，绑定同一全量复核证明。
3. `recorded_search_inputs` 共同读取九份原生来源，排除已用／保留棋局，保护全部保留历史、讲解主线、备选分支和颜色对应。每盘最多六根；零步战术局面保留其历史缺失边界。
4. 独立入口重新哈希并逐字段比较全部候选，重建保留范围，原生复演全部战术候选及每种完整实战来源至多 64 根；正式搜索接口再读入前 512 根并核验完整尾部。

候选输出为 `data/unused-recorded-paper-search-inputs-v1/`。当前队列只准备数据，没有学生搜索、教师推理或训练；最终可用数量必须等新课程全部完成生成后测量。五盘合法控制夹具的 18 个候选已通过相同独立入口及正式读取，属于接口检查。

`plan.json`、源码快照、`state.json`、各阶段日志和 `exit.json` 记录检查与续跑边界。存活队列继续观察；只有确认终止后才使用原入口和源码续跑。改变输入、配置或不可恢复的部分输出时，保留原目录并新建实验。

原始导出及派生数据不随源码发布；来源再分发许可尚未确定，见 [第三方说明](../THIRD_PARTY_NOTICES.md)。完整原生复核只证明记录一致和规则合法，后续有效搜索产量、训练收益、棋力及教学质量仍需实际验收。

## 兼容原导入清单的相对路径

部分早期原生导入清单将输出记为 `data/来源目录/games.jsonl`，后续队列传入同一文件的绝对路径。旧搜索准备直接按字符串索引，因而在完成课程足迹和已用历史准备后报错；依赖它的pilot也按前序失败退出，没有启动学生或教师。

`recorded_search_inputs` 现在在项目工作目录中规范化清单声明与请求文件的完整路径，再沿用原SHA256、字节数和文件身份检查。只有完整路径相同才可匹配；同名但不同目录的文件不会被猜测使用，指向同一文件的冲突哈希也会拒收。原清单和棋谱不改写，候选排序、分割、保留范围及每盘采样预算保持原实现。运行入口应与原准备队列一样先切换到项目根目录。

回归覆盖绝对路径调用读取相对声明，候选字节与原绝对声明相同；错误目录、冲突别名及改动后的棋谱均拒收。软件修复完成后仍须以新运行计划重新准备并独立读回完整候选池，实际搜索继续等待新四课、干净全参数讲解训练、能力验证和完整对弈基线。旧失败目录保留。
