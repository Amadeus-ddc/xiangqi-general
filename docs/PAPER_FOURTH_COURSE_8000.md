旧三课较 6000 步纠正 186 题、另有 85 题转错；新课纠正 75 题、另有 47 题转错。与 4000 步相比，旧课合计仍少 3 题，四课合计多 36 题。相邻轮次的提示和金标逐题一致，比较不依赖第三课与第四课之间的问法变化。66 个棋局 ID 产生这些问题，不能把 2600 题当作 2600 个独立棋局。

材料计算：当前静态 59/100→95/100，未来静态 58/100→91/100，合计净多 69 题。两者合计正确数 186/200 回到 4000 步的 186/200，但具体组成不同：4000 步为 99/100 与 87/100。200 个不同材料查询在两轮共 400 次既有原生核算，金标全部一致；这是同一项目规则代码的复核，不是第二套规则实现。数值绝对偏差总和由当前静态 89→11、未来静态 107→20。它描述恢复表现，没有建立具体训练机制或长期稳定性的因果结论。

第四课主要增益是未来吃子 55→69、未来将军判断 59→70；完整走法 76→78、将死 83→84。未来应将维持 38/100，控制关系 89/100；应将仍为最弱项。当前、未来静态斜线识别分别下降 3 题至 82/100 和 77/100，需要继续观察。

8000 次更新的全部损失和梯度连续有限；2048000 次有效样本呈现、填充 0。671806496 个 FP32 桥接/棋盘词参数有限且与实际源检查点逐位相同；原优化器数组没有独立复核。混合数据一轮为 11209 次更新，目前约 71%，5000 步预热已结束。相同配方下本轮出现回升，后续在 10000 步继续追踪稳定性；不能据此宣称强棋力或教练效果已经通过验收。

实际配方继续保持旧课 6%/6%/8%、新课 80%，旧课进入实际反向传播。选模指标为新课原始 QA 准确率，同分取更早；当前候选为 8000 步，停训决定为继续。最低 48000、上限 100000，每 2000 步完整验证及三次无提升的既有计划保持；用户后续明确指令优先。本轮没有改动训练配方、数据、优化器或冻结执行源码。
