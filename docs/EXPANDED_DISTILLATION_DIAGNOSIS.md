# 扩充蒸馏的实际训练、质量诊断与严格数据

截至2026-11-06，第一轮扩充开发蒸馏实际完成四遍、164次四卡全参数更新，但按原384条讲解验证NLL选择了起点0步，原轮次资格失败。原始实验完整保留，合格新轮次计数仍为零。实际末步权重已经另存并逐张量读回，只作为未获选开发候选，不替换原来的所选模型。[机器可读证据](../evidence/expanded-distillation-diagnosis-v1.json)记录实际产物哈希与范围。

## 字段顺序的配对检查

新1046条训练讲解把`branches`放在`evaluation`之前，原9823条训练讲解和384条验证讲解均把它放在最后。固定哈希选取64条验证及64条本轮已训练记录，每个JSON对象只改变字段顺序，逐条断言其所有值完全相同，按冻结原生损失函数比较。

| 原64条验证目标 | 父模型NLL | 实际164步NLL |
| --- | ---: | ---: |
| 原字段顺序 | 0.62882 | 1.32399 |
| 搜索训练字段顺序 | 0.71196 | 1.26445 |

两模型采用相同字段顺序后，原验证样本上的差距仍存在。64条已训练搜索目标在搜索字段顺序下的损失从1.39454降至0.11083；这是已见训练样本的拟合结果，不能测量新教师分布内的泛化。小训练集适配、回放覆盖与新旧教师分布尚不能由本项单独分离。

## 严格重新收集

对全部1046条合并训练记录进行原生一手将死检查，发现21条评分与所给变化不一致。随后从原五批1185份完整BF16教师回答重新执行收集：各批接受44、37、322、307、326条，共1036条，按完整历史去重保留1025条。五个来源均明确要求即时将死一致性；原查询、教师回答、拒收和失败实验保留。

新集合已完成原生合并及第二次完整重开，原384/512验证与测试文件逐字节一致。此过程没有新增学生、教师、引擎查询或SGD。该门槛仅覆盖即时将死评分，完整战略正文仍未全部验证。
