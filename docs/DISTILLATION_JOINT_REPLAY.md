# 讲解与蒸馏中的四课回放

原始完整讲解 SFT 后，相同 FP32 推理源码和 2600 道旧课题的正确数从 2465 降到 1896。模型仍是开发基线，尚不具备可靠教练的交付证据。这里补充真实旧课训练回放；保留率与讲解质量由后续同题评测确定。

## 独立的初始讲解联合训练

`runs/joint-replay-initial-sft-v1` 从已完成四课的干净权重初始化。每轮保留全部 9823 条讲解，四门旧课各选 614 条，共 12279 条；有限采样固定旧课子集，四轮、全局批量 16，对应 3072 次计划更新。累计 49116 次非填充样本呈现并不等于 49116 条独立样本。

样本比例为讲解 80%、每门旧课 5%，采用逐样本损失平均。讲解选择仍使用原来全部 384 条验证；原来的词元平均 NLL 不能直接与新损失比较。训练结束后自动检查同一 2600 道旧课题及三组各 384 个讲解局面，保留原始错误，并另作完整 BF16 教师盲评。辅助模型评分不能替代人类教学验收。

完整 4694274592 参数、624 个 FP32 张量的四卡原生预检已通过：连续 4 步与 2+2 步权重最大差为零，Adam 与随机状态无不一致；398 个解码器、224 个桥接和 2 个棋盘张量均更新。正式训练前三步已经产生有限损失和非零有限梯度。训练完成、遗忘改善和棋力提升仍待验证。启动读回只重建实际固定采样器的前三批并核对日志，不宣称又一次重新读取全部原生权重和优化器。

## 正式蒸馏也使用真实多源回放

蒸馏入口现在可接受 `replay_data_paths`。默认讲解单源合同保持；联合配方明确列出讲解和全部四课，使用逐样本损失，验证选择仍只使用讲解验证。

新数据预检要求完成的原始课程子集清单，重新打开实际训练与验证文件，逐条原生复算规则答案、历史和未来变化，并与全部讲解的训练／验证／测试共同检查隔离。所有实际训练和验证行使用学生的固定分词器检查完整监督长度；独立测试只用于保留与隔离核查，不生成学生答案、不分词、不训练、不选模。

```bash
python -m xqgeneral.distillation_preflight \
  --init "$XQ_PARENT" --parent-completion "$XQ_COMPLETION" \
  --data "$XQ_LABELS" --features "$XQ_FEATURES" \
  --foundation-preflight "$XQ_FOUNDATION" \
  --replay-data "$XQ_COURSE_REPLAY" --output "$XQ_PREFLIGHT"
```

训练模板的回放目录必须逐项匹配预检清单，`stages` 为 `explanation` 加四课，`mixture` 例如讲解 `0.8`、四课各 `0.05`，`loss_normalization` 为 `example`。原始文件、清单和索引全部进入完成合同；实际有限轮次验证也重新打开每个来源。修改回放文件后不能复用旧完成回执。

预算直接复用有限采样器的取整规则。例如 1000 条讲解加四课各 62 条，是 1248 行、全局批量 32 下每轮 39 次更新。不会按连续比例误算成 1250 行或 40 步。旧课原始可用行数、实际选择数和新讲解数分别记录；增加旧课行数不能触发“15 万条新蒸馏讲解”的规模标记。最大步数仍需按实际数据和验证曲线设定。

真实完整父缓存可以直接继承旧片引用，再只为新训练历史增加特征；不要求先实现小型子集缓存的继承接口。任何正式蒸馏 SGD 之前仍须通过完整模型四卡原生预检。

## 搜索数据与训练父模型的边界

精简子问题的 64 根试批已独立重建 37 条收取标签和 9 条拒收；最终标签产率为 57.8125%。同根原版本收取 44 条，两批不能相加当成不同原始根。新试批有 7 个源码模块差异，且服务器负载不同，不能当作严格单变量质量比较。

9 条拒收包括 3 条独占评分误差门槛、4 条中文记谱未配对 UCCI 证据、2 条在 8192 词元处截断且推理未结束。中文记谱未配对本身不等同于非法走法。收取门槛没有放宽，战略含义和人类教学质量仍需核查。实际矿工入口到收取结束约 6036 秒、约 22.07 条结构合格标签/小时；12 个子问题的生成速度比例不能替代整个管线实测。

当前搜索固定使用原 1792 步模型，新增联合 SFT 是另一个候选。正式蒸馏保持“实际搜索模型与训练父模型完全相同”的合同；选用新候选后，需要从该候选真实搜索，不能改写旧标签来源。扩展的 1536 个根仍是候选输入，必须完成搜索、教师汇总、跨批完整历史去重、原生隔离和分词检查，才能计入训练标签。

代码、受控 CPU 编排、真实数据准备和完整模型能力是不同证据。发布检查及实际进度见 `evidence/distillation-joint-replay-v1.json`；最终棋力、教学验收和模型交付尚未完成。

学生基座与混合词元统计的后续修复见 [基座证明衔接](DISTILLATION_MODEL_ASSETS.md)：父模型的独立固定清单进入词元预检及实际训练配方，额外回放长度也必须处于原生容量探针范围内。
