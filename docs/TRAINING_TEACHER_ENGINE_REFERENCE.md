# 初始讲解训练标签全量引擎参考

对现有10758条训练标签逐条评分并完成独立读回。10758条结构、推荐走法和完整主变化均合法；10644/10758（98.94%）推荐走法无既定阈值下的明显失误，9823/10758（91.31%）完整主变化的每一步均通过该检查。114条推荐走法、935条完整变化未通过对应检查，这两项不应相加作为不重复样本数。原标签与错误保留，正式讲解训练数据的资格筛选仍待完成。

该参考只读训练标签，未读取验证或独立测试答案，未加载学生、语言教师或GPU模型。它不是学生成绩、正文语义评价、人类评分或实战棋力／教学收益证明。标签来自既有初始教师数据；7619条没有颜色派生标记、3139条是已有颜色派生，未标记项也不等于独立人类对局。

评分使用固定Pikafish与材料相关WDL映射，每步选择相对引擎最佳候选的预期得分损失须严格小于0.10。它不是经过人类对局校准的胜率。每次引擎请求预算100万节点；按需另评推荐招及变化中各步，不能说每条标签总共仅消耗100万节点。

14次不限招请求在节点截止时未给出最佳招的完整评分。协议保留原始输出和原最佳招，另以同样100万节点、限制为原最佳招的请求取得完整评分；严格解析后仍要求同一最佳招。该额外请求单独计数，未改标签或学生预测，其他协议错误仍拒绝通过。先前失败尝试及330条复用行的原字节也保留并验证。

独立读回重演全部原始标签与完整历史，重解析83020个留存评分对象，重算63746个合法主变化半回合的损失和全部统计，并核验14次额外同招请求。读回自身未调用引擎。完整变化通过不是正文战略理由已验证的同义词，源优化器或任何学生训练收益也不在此次范围。见[机器可读证据](../evidence/clean-teacher-training-engine-reference-v2.json)。

当前课程学习保持原数据、配方和选模规则。正式讲解SFT仍须在四课全部结束、训练数据资格确认和实际四卡全参数预检通过后启动；之后还需真实学生搜索、足量蒸馏及独立验收。
