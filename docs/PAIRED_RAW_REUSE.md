## 显式复用完成的原始结果

改变协调器后使用新输出目录，可在评测配置中声明完成产物：

```json
{
  "reuse_raw_validation": {
    "normal": {
      "path": "runs/previous-validation/normal",
      "manifest_sha256": "实际完成清单的64位小写SHA256"
    }
  }
}
```

示例中的目录与SHA必须替换为实际值。该字段可分别声明`normal`、`zero`、`shuffled`。未声明的组按原流程执行；已声明的组必须已经完成，不会因校验失败而重新生成或覆盖。

复用要求原模型、全部缓存、验证数据、引擎、预算、问法及原始回答绑定一致。完整源码清单必须保持相同；只有不参与原始模型生成和引擎评分的`clean_sft_evaluation.py`协调器可以变化，所有其他源码文件逐一相等。改变模型加载、提示、推理、训练公共函数、规则或评分文件都会拒收。旧清单中的真实生产源码身份保持，新的评审与汇总使用自己的源码身份。

正常组的正文盲评直接读取声明目录中的原始评分文件。源清单和全部输出在后续阶段持续检查，最终完成清单同时绑定这些原路径；不复制并改写旧清单。未完成的产物继续保留其失败状态。
