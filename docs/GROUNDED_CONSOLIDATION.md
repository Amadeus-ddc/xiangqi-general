# 汇总讲解的分数与原生事实核对

`grounded_child_prose_v2`给汇总教师增加根方视角的分数表、应将方式和逐线吃子统计。它保留实际学生子讲解，让教师核对并汇总原文；不生成替代讲解，也不改变搜索接收、评分误差、历史或分割隔离门槛。

原提示同时提供根方视角的`target_fields.branches`和对手视角的原始子评分，但系统把“子评分”统称为对手视角。新版本明确区分这两个来源，要求正文引用已转换的分支表，不再反号；独立引擎根评分与学生分支估计仍分别标识。厘兵单位和正负杀分的解释也在提示中说明，有限变化不作为实际杀棋步数或强制结果的证明。

新增的`native_coaching_evidence`由给定棋盘和实际提供的合法变化计算：

- 根方是否正在被将军、将军子，以及各候选如何解除炮将、车将或马将。
- 根局和每条变化末尾的双方棋子数量、双方分别吃到的子，以及各自剩余数量的变化。统计没有棋子价值权重，不会把车换炮自动判成战略上有利或不利。
- 首着落点的行棋方纵向路数与零起始横线坐标，避免把第七横线说成七路。

这些是原生规则和给定变化的摘要，共享现有规则实现，不是独立求解、额外引擎搜索或战略证明。只有根局正在被将军时才生成候选应将方式；不合法的给定变化、未按合同声明的分数和被篡改的核对表会被拒绝。教师仍可能误读，最终原文仍需复核。

在一个新的搜索实验中显式指定：

```text
--child-prompt-profile full_explanation --consolidation-profile grounded_child_prose_v2
```

未指定的默认提示和显式`raw_child_prose_v1`保持原样。数值专用子提示不能使用新版本，缺少实际非终局子讲解时也不会由核对表补齐。已有原始查询、回答和矿工清单不能改名成新版本后冒充原运行；新神经生成与训练接收需要各自的新目录和完整来源证明。

新增CPU案例覆盖已转换分数不再次反号、增加炮架与塞马腿应将、双方吃子和净计数、路与横线区分、核对表篡改、缺少子原文、实际矿工目标／轨迹不变。相关53项检查通过。

2026-11-11的真实输入检查重新读取首批433个实际查询，旧提示全部逐条相同，实际子原文、目标、逐步事实与记谱未变；新吃子统计与保存的逐步吃子事实逐线一致，其中35个根正在被将军。使用本地教师的实际分词器与low聊天模板，新提示为2018至7441词元，全部保留原8192词元回答预算并满足16384词元上下文上限。第一次未压缩JSON空白的尝试挤占了回答预算，按失败保留；新尝试只压缩JSON布局空白，不删事实或子原文。

完整CPU套件和打包检查另行核验。这些检查共享现有规则，不证明新教师输出或学生能力已经改善。真实质量对照必须使用相同根、权重和生成配方，保存全部原始回答并重新审阅。
