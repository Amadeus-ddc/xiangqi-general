# 搜索讲解的复核剔除

结构、走法和隔离检查通过，仍可能留下无依据的讲解。复核后需要剔除某条正文时，
使用 `xqgeneral.collect_search --prose-review-exclusions review.json`，输出到新的目录。
原始查询、教师回答和已完成的数据集不修改。

复核文件格式如下，三个哈希均为真实文件或字符串的 SHA256：

```json
{
  "profile": "search_prose_exclusions_v1",
  "queries_sha256": "<原始 queries.jsonl 的 SHA256>",
  "responses_sha256": "<原始 responses.jsonl 的 SHA256>",
  "reviewer": "记录实际复核者及复核方式",
  "exclusions": [
    {
      "id": "实际已通过原生校验的标签 ID",
      "explanation_sha256": "<最终 explanation 字符串按 UTF-8 编码的 SHA256>",
      "reason": "逐条记录为什么需要剔除"
    }
  ]
}
```

只能剔除当前查询、回答所产生且已经通过全部原生门槛的标签。未知、重复、原生已拒收
或正文已改变的 ID 都会失败。空复核列表请直接省略该选项。全部剔除时保留拒收原因，
不会把空目录记作完成的数据集。

记录中的复核者是来源说明，不是经系统认证的人工或独立专家。剔除不证明其余正文
正确；输出继续明确标记全部战略语义尚未验证。该入口不代写、修复或伪造教师回答。

合并搜索数据时，以及直接使用带复核剔除的单个集合进行训练预检时，都会从原始挖掘
与真实教师生产记录重建标签和剔除结果，核对复核文件绑定、正文和拒收原因。
至少 32 个不同历史的门槛、事实／历史／走法／评分过滤和保留集隔离继续生效。
