# 原初始讲解模型的384局完整开发对弈

2026-11-06（UTC+8），原初始讲解模型的384局开发对弈已完成，并通过原冻结源码的独立读回。结果为0胜、383负、1和；277局因原始模型走法非法而弃负。它尚未达到强棋力或可靠象棋教练的交付目标。这份结果作为新联合回放模型和后续正式蒸馏模型的同设置对照保存。

## 对弈设置与结果

实际模型仍是原初始SFT按验证NLL选出的1792步完整FP32权重，SHA256为`66f375842809b8140e612116413dac28c88e996267f60d01ae3bcc2f9b123d61`。没有改选末步，也没有新增训练。64个受保护的真实棋谱验证开局分别让模型执红、执黑，逐一对弈100、1000、10000节点预算的固定皮卡鱼，共384局。每局最多从开局继续256半步。

模型按原始讲解策略生成，再提取首着；每次最多生成768词元。没有合法走法约束、引擎替换或非法回答修复。完整讲解合同不通过与首着非法分别记录，不能把所有讲解错误都算成对弈弃负。

其余终止原因为106次将死或困毙失利、1次按原生AXF重复／步数规则结束。截断局为0；截断不记为和棋，不换算人类等级分或Elo。5100次实际模型回合中，299次完整结构、变化与走子事实合同通过；这不是另一次正文教学评分。64个开局被复用于颜色和预算比较，不能把384局当成384个独立棋局样本。

逐局失败核算显示，381/384局的第一次模型走法合法，但277次非法弃负中有274次发生在至少一次合法模型走法之后；弃负发生在该局第几次模型回合的中位数为10、最多51。全部277次失败回答均能解析为JSON，也都提供了四字符棋盘坐标，实际着法仍不合法。这说明持续对弈的原始走法质量存在问题，不能只修正JSON格式；它没有单独定位训练数据、模型或解码中的唯一原因。后续比较必须保留完整棋局，不能用单步QA或开局首着合法率代替。
