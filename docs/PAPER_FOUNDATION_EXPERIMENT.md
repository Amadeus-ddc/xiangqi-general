# 论文对齐的新四课实验

核对日期：2026-10-11。新配方为 [foundation-paper-v1.json](../configs/foundation-paper-v1.json)，数据预算为 [paper-task-position-budgets-v1.json](../configs/paper-task-position-budgets-v1.json)。当前原冻结课程保留；这套新实验从固定 Qwen3-4B 预训练基础开始，没有课程或讲解权重初始化。

## 组合与选模

新实验组合 26 类原生问答、16 块 2560 维全宽桥接、16 个注意力头、零门控初始化、FP32 可训练主参数和 BF16 计算。Px0 与原语言解码器冻结。训练按回答 token 平均交叉熵；通过有限混合集打乱完整遍历，按论文比例混入旧课，使用磁盘问答索引与分片专家特征。

原始生成验证仍保存当前及所有旧课的答案和分数；当前课正确率是主选模指标，旧课回放另行报告。训练中的 NLL 也只取当前课。参考总分／最弱题型目标只作诊断，不触发这份新策略的提前停止；独立测试始终不参与选模。

同分选较早步数、耐心三次，以及最低停止步数是明确的本地规则。候选从预热后的检查开始，达到最低训练预算后才允许因平台期停止；此前较好的合格候选继续保留。每课生成验证间隔 2000 步、每题型 100 道，与公开当前课验证上限对应。公开配置及论文未给完整最终选模规则，见 [训练审计](PAPER_REPRODUCTION.md)。

## 数据与来源容量

课程根来自完整原生导入的人类、电脑、人机和公开实战，保留棋局预分割、完整历史、实际未来及将死依据。初始讲解和后续搜索可另用已准备的战术来源。记录棋手走法不作为最佳走法标签；课程答案由棋规计算。

普通训练题型请求根数取作者请求的四分之一、取整为正整数；将死判断每门动态训练课请求 10000 根。每题型验证请求 100 根，独立测试请求 1000 根。训练多问题数、累计答案频率及难例来源比例继续使用已有作者形式。实际问答数受根容量、查询实体数和去重限制，不能把预算当成完成数据量。

`scarce_dynamic_tasks_first_xiangqi_v1` 先选择将死、解将、将军，再选走法、攻击／保护和吃子，避免通用题消耗稀有局面。静态顺序保持原合同。这是本地容量适配；原选样默认不变。每份完成清单声明顺序，并完整读回重建。来源有限、耗尽不循环填数，实际数量、类别比例及缺口必须报告。新记录根本身红黑较平衡，本次不另加颜色镜像。
