# 初始讲解模型：三组完整开发验证与正文盲评

2026-11-05（UTC+8），选中1792步模型已完成正常、清零、不同历史错配三组讲解验证，以及正常组全部384条的完整未量化BF16教师辅助盲评。原始回答、非法走法及无效评分均保留。当前模型仍未达到可靠象棋教练的交付质量。

这三组使用同一批384道开发题，不是1152个独立局面。每组最多生成768个词元，引擎核验每个搜索位置使用固定皮卡鱼100万节点；没有用引擎替换学生的非法回答。最终独立测试未使用。
