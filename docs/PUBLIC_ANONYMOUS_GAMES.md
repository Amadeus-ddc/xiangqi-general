# 匿名玩家实战的可复现导入

这批来源为后续搜索蒸馏补充匿名玩家的原始实战。当前完成的是采集、完整历史原生导入和独立读回；后续保留局面／颜色隔离、实际学生搜索及神经标签产量仍待执行。现有四课、初始讲解和512根pilot继续使用各自冻结输入。完整模型训练、棋力及教学验收尚未完成。

## 来源与实际容量

[elephantchess 数据页](https://elephantchess.io/about/datasets)明确提供匿名标准象棋PvP导出，并为用户对局数据声明GPL-3.0。两个月份的下载链接实际指向同一六月ZIP，只获取一份；不按页面月份或标称容量累加，也不猜测其他下载地址。原始与派生数据不随源码发布，见[第三方说明](../THIRD_PARTY_NOTICES.md)。

实际压缩包11249110字节，11个CSV、102281791字节解压内容，包含10471个来源棋局标识和522619条走子记录。文件身份、源码哈希、完整统计及证据边界见[独立读回证据](../evidence/public-anonymous-recorded-games-v1.json)。

逐盘验证后新增8828盘、486754个半回合，与八份已有完整历史来源的132651个规范棋局标识没有整盘重复。按固定种子20261051、规范完整历史在制作问答前分割：训练7072、验证886、独立测试870。首步记录年份2023／2024／2025／2026分别为90／495／3130／5113盘，涉及6303个匿名标签；标签数量不代表经认证的独立真人数。

1643条记录隔离保存：不足20个半回合1468条；原生完整历史终局后仍有着法165条；来源声称的规则终局与原生终局不符7条；非法着法1条；未结束／结果状态不支持2条。终局冲突可能涉及规则口径，原始着法和错误保留，没有截断或修复为合格棋局。

## 完整历史合同与独立复核

导入入口`xqgeneral.elephant_games`保持CSV提供的零基ICCS坐标及行顺序，拒绝缺失或重排编号、局内元数据变化和时间冲突。只接纳标准初始局面开始的完整来源主线；每步按原生规则复演，验证完整历史终局及结果。源站分析和CPL字段只参加原值摘要，不作为训练标签。

独立入口重新读取所有CSV，为全部10471条来源核对原始字段摘要、CSV范围和唯一去向，直接调用稳定原生规则重新复演，再比对全部8828盘的着法、每个历史FEN、终局、分割和来源事实。同时重新流读八份已有完整历史文件、重算规范身份及分割，核验去重结果。这个入口未调用新增导入器的分组或原生接收函数。

整盘去重和预先分割完成后，仍须为新版本候选检查所有保留根、记录未来及颜色对应的局面重叠。零步战术局面不传给完整棋局去重接口，但仍须参与后续局面隔离。当前新增可用搜索根和神经标签均为0，学生棋力与讲解收益没有测量。

## 复现命令

在项目根目录使用新输出位置获取公开导出。下载入口只接受数据页明确提供的单个匿名象棋ZIP，记录页面及文件哈希；月份链接冲突、声明变化或不完整下载会拒绝生成成功清单。

```bash
python scripts/fetch_elephantchess_games.py --output data/sources/anonymous-pvp-v1
python -m xqgeneral.elephant_games \
  --acquisition data/sources/anonymous-pvp-v1/manifest.json \
  --output data/anonymous-pvp-native-v1 \
  --workers 8 --seed 20261051 --minimum-plies 20
```

已有完成的原生完整历史来源可重复传入`--previous data/已有来源目录`。导入会保留接收、隔离、重复及归属差异记录，并输出绑定原始文件和执行源码的manifest。已存在的采集或导入目录不会覆盖；长任务应放在tmux或调度器，按实际进程与退出记录检查，完整独立读回之后再制作新的搜索候选。
