# 有限课程混合与完整遍历

核对日期：2026-10-10。实现位于 [finite_training.py](../src/xqgeneral/finite_training.py)，证据见 [CPU、作者函数与 CUDA 续跑对照](../evidence/paper-finite-training-v1.json)。这是新实验可显式使用的训练方式；正在运行的四门课程仍使用原冻结配方。

## 混合与每轮访问

作者固定版本的 [mix_arrows.py](https://github.com/queen-project/queen/blob/c372da22ca75e95c3c79bee8a83c220fc54d0dcb/datagen/mix_arrows.py) 先构建有限混合集，再由 [训练入口](https://github.com/queen-project/queen/blob/c372da22ca75e95c3c79bee8a83c220fc54d0dcb/train.py) 打乱遍历。本地的显式配置为：

```json
{
  "training_data_profile": "author_finite_mixture_epochs_xiangqi_v1",
  "mixture_seed": 0
}
```

训练仍须声明课程 `mixture`、种子、全局批量和微批量。最大权重课程保留全部训练行，其他课程各选 `round(主课行数 × 旧课权重 / 主课权重)` 行；权重相同时按配置出现顺序确定主课。各旧课先按混合种子独立打乱，再取固定前缀。容量不足直接拒绝这份配方，由新实验调整实际数据预算。验证和独立测试不参与混合。

固定子集构建一次，每个 epoch 使用 `seed + epoch` 打乱全部已选行。它保留出题器产生的实际题型频率，旧课子集不会每轮重选。例如第二课按 90% 新课、10% 旧课形成有限混合集；旧课行实际进入梯度更新。来源容量、所选行数、取整后的比例、行身份摘要和每轮更新数写入 `training_data.json`。

单卡保留最后不足一个微批量的尾批。多卡按作者加载器的均衡分片方式，最多从本轮开头补 `world_size × micro_batch_size - 1` 行，使各卡拥有完整微批量；不补齐到整个有效批量。补行只用于分布式批尾，另行计数，不增加独立数据量。全局有效批量须整除卡数乘微批量。

检查点的 `data_state` 保存固定混合集合同、epoch、当前轮的更新位置和累计有效／补行数。恢复时重新生成同一混合集并逐项核验，改变种子、混合、所选行、分片几何或缺少状态都会拒绝精确续跑。原训练入口的源码、输入哈希、优化器和随机状态守卫继续生效；配方变更使用新目录和明确的初始化权重。

## 讲解训练预算

显式有限模式的 SFT 先统计主数据和回放文件的训练行，按相同规则计算有限混合集。主讲解课程必须是最大权重来源，`epochs` 必须为正整数，更新上限为：

`min(max_steps, ceil(混合行数 / 全局批量) × epochs)`。

例如 10,758 条讲解、没有旧课混合、全局批量 16、四遍，是每遍 673 次更新、共 2,692 次更新，包含每遍的尾批。当前已排队配方未启用这个模式，仍为按样本数折算的有放回训练，不能称其已经执行了四遍完整访问。

## 验证与范围

- 41 项新增测试覆盖容量、固定子集、题型频率、完整轮次、单／多卡尾批、状态拒收、旧行为兼容及 SFT 预算。标准全套 1,004 项通过，154 份源码／测试绑定前后不变。
- 固定作者版本的原样 `mix_arrows` 函数用真实 Hugging Face 数据集执行六组两／三／四课混合；全部已选行 ID 与本实现一致。实际 Accelerate `SeedableRandomSampler`、PyTorch `BatchSampler` 和多卡 `BatchSamplerShard` 的 243 组容量／卡数／微批量／epoch 对照，逐卡所有更新批次顺序一致。库版本和源码摘要在证据中绑定。
- 实际 CUDA 训练入口使用构造的小张量模型执行八次更新，并与第四次中断后恢复到第八次对照；可训练张量、优化器、CPU／CUDA 随机状态、损失、监督词元和批次轨迹逐位一致。这是训练与续跑协议检查，没有加载预训练学生或专家，不证明象棋能力。
- 两个控制各使用 85 份冻结模块，完成后重新核验；完整证据读回重新哈希 427 份文件，包括原生产配方和 67 份生产源码。

这些对照证明所测试版本的混合和批次顺序，没有证明作者完整训练随机流、可选长度分组模式或多卡神经模型优化轨迹相同。主训练入口仍将课程行载入内存，大规模数据的磁盘读取及特征分片尚需单独完成。全宽桥接、26 类完整数据、当前课选模和回答词元平均损失仍需组合成新配方，完成四课、讲解训练、搜索蒸馏及独立棋力／正文验收。
