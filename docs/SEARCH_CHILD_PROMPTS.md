# 搜索子局面的精简请求与真实标签试批

2026-11-05（UTC+8），新增可选的 `numeric_six_ply_v1` 子局面请求。默认仍为 `full_explanation`，已有配置和完成合同不变。新配置仅用于 `move_eval` 子局面合同；根局面仍请求完整讲解，子局面请求 `move`、六个半步的 `pv`、三个 `candidates` 与整数 `evaluation`，省去未使用的正文、事实和分支字段。若提前终局，主线停止。

可在搜索CLI添加 `--child-contract move_eval --child-prompt-profile numeric_six_ply_v1`，或在试批配置添加 `"child_prompt_profile": "numeric_six_ply_v1"`。未知版本及与完整子合同不匹配的请求在模型加载前拒绝。实际请求、版本和SHA256保存在每次精简生成的 `prompt` 字段中；数值子分析被递归复用时，这些记录保持。完成清单记录请求版本，改变版本后不能续用原合同。

采样、逐根／逐次随机种子、输出预算、候选填充、递归优先级、引擎节点数、变化净化、分数误差门槛和保留集隔离规则保持。精简请求不等于降低六个半步的请求长度；实际模型仍可能回答非法或不完整变化，后续检查继续保留并拒绝相应错误。

## 同一完整学生的实际调用对照

来源为四个训练根中的12个实际子局面，不是12个独立测试根。使用选中1792步模型、624个FP32张量／4,694,274,592个参数，4096词元预算及相同采样与随机种子，交替运行完整与精简请求；另有一次8词元预热，共25次学生调用，无新教师／引擎查询或学生训练。

| 12次调用的指标 | 完整请求 | 精简请求 |
| --- | ---: | ---: |
| 生成词元总数 | 4,962 | 924 |
| 总耗时（秒） | 230.93 | 42.33 |
| 耗时中位数（秒） | 19.46 | 3.56 |
| 走法／分数子合同有效 | 8 | 8 |

两组全部回答均输出六个半步。此固定12例的总耗时比为5.45；共享服务器时序和小样本不能支持整轮搜索加速或质量不降的结论，精简组分数误差及完整主线合法数还有变差。当前消费者保留已保存的关闭AMP权重缓存设置，与最初探测消费者不同；在这12例中，两种请求共24份原始回答和完整生成词元序列均与此前探测逐一完全一致，该一致性不扩展到未执行的根。

19项新增回归、151项相关及1974项完整CPU检查、构建与发布检查通过。实际完整学生调用在完整CPU检查通过后执行，112份模块、304份源码／测试／配置及原生输出另行读回。回归还检查默认原始轨迹、逐次种子、真正省略正文的子输出、递归复用、保留位置拒绝、引擎分数错误拒绝、CLI／协调器转发及改变合同拒绝；CPU夹具不用于声称模型质量。
