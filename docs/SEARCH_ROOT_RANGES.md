# 固定顺序分段搜索与数据扩展准备

2026-11-05（UTC+8），记录棋局搜索新增可选 `--root-offset`，试批配置对应 `root_offset`。它表示已完成候选池中的零基起点，沿用按种子与完整历史键排序的原顺序；只支持 `--recorded-inputs`。省略时，原有默认选择、原始参数合同与输出保持。

例如 `--limit 512 --root-offset 512` 选择索引512到1023；另两段可使用1024和1536。负数、布尔值等非法偏移拒绝；非零偏移的完整请求区间必须处于候选覆盖范围。协调器在加载模型前检查覆盖，实际完成时仍核对请求数。对未选中的前缀和后缀也继续核验整个池的训练归属、顺序和保留位置合同，分段不会跳过这些检查。

采集器使用矿工清单中同一偏移重新验证原始根或其递归后代的所有权，不能把另一分段的请求冒充本段。偏移写入续跑合同，完成凭据记录实际偏移与有序根ID的SHA256，改变偏移后必须使用新的输出。候选根和搜索完成、合格标签、正式训练仍是不同状态。
