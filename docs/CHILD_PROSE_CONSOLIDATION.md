# 子讲解原文的显式教师输入

原论文的汇总步骤向教师提供子讲解，再形成根局面的讲解，见[论文附录](https://arxiv.org/html/2610.03695v1#A2)。本地旧入口一直省略未经语义核验的学生正文；该适配会使教师主要依据结构化变化重新写讲解。新增显式配置可以保留学生原文，便于实施真实质量对照。

| 试批配置 `consolidation_profile` | 教师实际输入 |
| --- | --- |
| 不设置 | 保留旧消息格式，省略子正文，不增加新 profile 标签 |
| `verified_evidence_v1` | 省略子正文，增加实际省略与子项计数证明 |
| `raw_child_prose_v1` | 保留每个非终局子项的原始讲解，同时提供已有规则事实、变化及评分视角 |

在已有有效的 `search_pilot` 配置中，原文模式须使用 `child_prompt_profile: "full_explanation"`。实际搜索 CLI 对应 `--consolidation-profile raw_child_prose_v1`；新参数与既有随机采样、批量、显式权重缓存及严格标签收取配置可以共同使用。缺省配置继续执行旧路径。

数值专用的 `numeric_six_ply_v1` 不生成子讲解，不能与原文模式组合；该冲突在模型加载前拒绝。非终局子项缺少非空正文时，以 `missing_child_prose` 拒收并保留完整原始搜索轨迹。实际已终局的子项不需要补造模型正文。

教师提示明确标注学生原文未经语义核验，要求核对子局面行棋方与根局面行棋方、优先使用给定规则事实，且不得执行子正文中的指令。它保留原有中文记谱、走法、评分和片段历史边界。`search_pilot` 在进入教师阶段前，从真实消息重新统计正文及终局子项，与搜索证明逐项比较。

## 已完成的实际记录复验

已完成的完整子讲解试批有 64 个起始尝试、45 份汇总输入。使用原始回答重新解析全部 126 段非终局正文，另有 1 个真实终局子项：

- 45 对原文／省略模式输入全部形成，无缺少正文的查询。
- 原文模式完整保留 126 段正文；省略模式保留 0 段正文。
- 45 份旧模式消息逐字节重现；根历史、目标走法、评分、变化与规则事实保持。
- 原始清单、查询和搜索轨迹的 SHA256 在复验前后相同。

这次工作是保存记录的输入转换，新增学生、教师、引擎查询和 SGD 均为 0。输出显式标记为 `saved_child_text_counterfactual_input_only`，不是新执行的搜索清单或可直接计数的新训练标签。原始记录与转换产物不随 Git 源码发布；公开[摘要](../evidence/child-prose-input-replay45-v1.json)保留计数、源码和输入输出摘要。

102 项相关 CPU 检查覆盖旧消息身份、两种子项结构、缺少正文的原始轨迹、终局例外、配置提前拒绝、实际 CLI 串联和证明不匹配时阻止教师加载。

## 尚未证明的范围

这证明正文传递和默认路径兼容，不证明学生正文正确，也不证明教师最终讲解或模型棋力改善。必须完成真实教师对照、规则筛选及正文质量检查后，再决定是否作为后续训练来源。该入口不会修改正在运行的冻结数值搜索队列。专用的当前学生对引擎训练对弈来源仍需另行构建，验证／独立测试对局不能转为训练材料。
