# 论文形式的全宽桥接

`bridge_architecture: flamingo_dense` 选择与论文主模型形式一致的桥接：16 头全宽交叉注意力、解码器宽度两倍的 FFN、ReLU²、三个 LayerNorm 和两个 tanh 门控。专家仍为中国象棋 Px0，读取 90 格特征；语言模型仍为固定 revision 的 Qwen3-4B-Instruct-2507。模块插入位置和专家层深由实验配置声明。

对应来源是 [论文第 3 节及附录](https://arxiv.org/html/2610.03695v1) 和作者固定版本的 [DenseXAttn](https://github.com/queen-project/queen/blob/c372da22ca75e95c3c79bee8a83c220fc54d0dcb/models/flamingo.py)。论文写零门控，公开实现默认采用非零门控与零注意力输出投影。本实现明确选论文形式：两个门控从零开始，输出投影保留随机初始化；首步保留原语言模型输出，同时门控可以得到梯度，随后专家投影开始学习。完整来源冲突见 [复刻对照](PAPER_REPRODUCTION.md)。

新模型配置须明确写入：

```json
{
  "bridge_architecture": "flamingo_dense",
  "bridge_heads": 16,
  "bridge_width": 2560
}
```

这些字段是模型结构声明，须与完整的新实验配方一起使用。宽度必须等于语言解码器宽度。旧配置没有这两个新字段时仍解析为 6 头瓶颈结构，以保持既有实验身份。续跑和课程继承均拒绝改变结构或头数；正式讲解 SFT 会从所选课程检查点继承这些字段。

在作者 2048 维解码器、1024 维专家条件下，16 块为 469,925,920 个桥接参数，与论文约 470M 的结构规模一致。在本项目 2560 维解码器、512 维专家条件下，16 块为 671,268,896 个桥接参数，加两个 105 词的棋盘嵌入共 671,806,496 个可训练参数、226 个张量。维度增加源于基础模型不同，不能据参数数量声称复现作者权重或棋力。

CPU 检查覆盖零门控首次梯度、打开后专家梯度与上下文依赖、冻结解码器、FP32 主参数的 BF16 计算、全部桥接及棋盘词张量交接、完整解码器初始化和旧配置兼容。大维度计数使用 meta 张量，没有加载基础模型权重。证据见 `evidence/paper-dense-bridge-cpu-v1.json`；标准入口为 `.venv/bin/python -m pytest -q`。

另以固定作者源码的桥接类作 CPU 数值对照：复制同一组权重，分别设置零门控和非零门控；两次前向、全部 14 个参数的反向梯度及文本／专家输入梯度逐位一致。只执行经过核验的模块定义，没有导入作者整个模型、加载权重或运行作者训练；该检查验证结构等价，不证明训练收益。

这一步交付模型实现和 CPU 合同验证。全宽结构的真实多卡训练、显存和吞吐、新四门课程、后续讲解及独立棋力尚未验证。新课程还须补齐论文题型、难例池、token 平均损失、有限数据遍历和当前课选模；使用新的实验目录与预检。当前瓶颈结构训练的配置与冻结源码保留。

新组合的当前课选模、容量适配和真实预训练四卡恢复已另行验证；完整数据准备与正式训练状态见 [新四课实验](PAPER_FOUNDATION_EXPERIMENT.md)。以上原冻结运行及历史审计结论保留。
